About:

Differential testing of the two RISC-V instruction selectors. For every llc RUN line in llvm/test/CodeGen/RISCV/*.ll, the input is compiled with -global-isel=0 and with -global-isel -global-isel-abort=2 -pass-remarks-missed=gisel.*. Mutants come from ir-mutate, a standalone driver for llvm/lib/FuzzMutate.

Function statuses: identical (same asm after label normalization), different (same instruction count), better/worse (GlobalISel emits fewer/more instructions), fallback (GlobalISel gave up and SelectionDAG was used). crash counts configurations where GlobalISel llc failed but SelectionDAG succeeded.

miscompile means the generated code computes something else. Functions whose assembly differs are sanitized (ir-mutate -sanitize replaces undef/poison, drops poison-generating and fast-math flags, and guards divisors and shift amounts), linked into a freestanding harness (ir-mutate -harness) that calls them on 64 pseudo-random argument tuples and hashes the return value and a memory arena, and run under qemu-user. The function is reported only when two SelectionDAG builds at different -O levels agree and GlobalISel differs, which filters out results that still depend on undefined behaviour or on the frame layout. Compiler Explorer compiles RISC-V but cannot run it, so miscompiles have no remote verdict.

Fallback categories are normalized: vector element counts become N (<4 x s32> and <8 x s32> are the same gap) and non-standard scalar widths are bucketed to the next standard width with a trailing ~. NEW marks a category no earlier run reported; M marks one that only mutants reach. The explore pass keeps only a few occurrences per category and counts the rest, which is what a * on a count means.

Snippets are the smallest candidate that reproduces the finding with the local llc: the single function extracted with llvm-extract (for crashes, the first function that reproduces), optionally reduced with llvm-reduce. Compiler Explorer links are created only after compiling the snippet remotely on every pane in the link; the verdict compares the remote result with the local one. "reproduces" means the same category on trunk; anything else usually means trunk moved on.

Within a run, findings are ordered miscompile, crash, fallback (categories only mutants reach first), regression, and the leading --detail-limit of them get a snippet and a page; the rest are listed in the run's table only. Older runs keep only their summary and findings table; snippets and occurrences are kept for the most recent runs of each label. Source: zeyi2/llvm-fuzz.
